# Password Strength Checker

A console-based Java application that analyzes password strength 
based on 5 security parameters and provides improvement suggestions.

## Features
- Checks minimum length (8+ characters)
- Detects uppercase, lowercase, digits, special characters
- Scores password out of 5
- Gives improvement suggestions
- Follows NIST 800-63B password guidelines

## How to Run
```bash
javac PasswordChecker.java
java PasswordChecker
```

## Tech Stack
- Language: Core Java
- Concepts: Loops, Boolean flags, String methods, Character class
